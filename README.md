# Employee Attendance Management System

A robust backend application built using *Spring Boot* to manage and track employee attendance records efficiently.

---

## 🚀 Features
* *Employee Management*: CRUD operations for employee data using EmployeeRepo.
* *Attendance Tracking*: Automated system to log and monitor daily attendance.
* *Database Integration: Powered by **Spring Data JPA* and *MySQL* (configured in application.properties).
* *RESTful API*: Clean architecture with separate layers for Controllers, Services, and Repositories.

---

## 🛠️ Tech Stack
* *Framework*: Spring Boot 3.x
* *Language*: Java 17+
* *Database*: Hibernate / Spring Data JPA
* *Build Tool*: Maven

---

## 📂 Project Structure
Based on the current repository:
* src/main/java/com/example/demo/: Core application logic.
* src/main/java/com/example/demo/repository/: Data access layer (EmployeeRepo).
* src/main/resources/application.properties: Database and server configurations.
* pom.xml: Dependency management.
